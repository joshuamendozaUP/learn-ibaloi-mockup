# Learn Ibaloi Mockup

Interactive mockup for a community-governed Ibaloi language learning app.

The primary entry point is `index.html`, a polished mobile-first learner mockup. Earlier design explorations are kept in `prototypes/` for reference.

## Concept

This mockup explores an Ibaloi-first learning experience where AI supports practice without replacing community authority. The design emphasizes:

- visible source, locality, permission, and review status
- gentle vocabulary and phrase practice
- grounded answers instead of unrestricted translation
- safe deferral to human/community review when evidence is insufficient
- reflection that separates language performance from identity or belonging

## Files

- `index.html` - primary branded mockup
- `prototypes/ibaloi-learner-branded-mockup.html` - embeddable branded fragment
- `prototypes/ibaloi-learner-flow*.html` - learner journey map
- `prototypes/ibaloi-learner-sketch*.html` - low-fidelity sketch flow
- `prototypes/ibaloi-wireframes*.html` - broader learner/community/research wireframes
- `assets/` - guide character and icon assets from the mockup source folder

## Preview

Open `index.html` directly in a browser, or run:

```bash
npm run serve
```

Then visit the local URL shown in the terminal.

## Research Boundary

The mockup uses draft/example Ibaloi terms and labels. Before implementation, learner-facing language content, cultural material, local variation, and permission rules should be reviewed with Ibaloi speakers and community representatives.
